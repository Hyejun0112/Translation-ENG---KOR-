==============================================================
  Plant O&M Translator v2.0  사용설명서
  발전플랜트 O&M Manual 영문 PDF → 한국어 PDF 번역 도구
==============================================================

[1] 무엇을 하나요
  - 그림·표·도면·괘선은 그대로 두고 글자만 한국어로 바꾼 PDF를 만듭니다.
  - Bluebeam Markup·스탬프·링크·북마크는 원본 그대로 유지됩니다.
  - 도면·데이터시트·부품목록 페이지와 Tag·모델·도면번호·수치+단위는
    원문 그대로 둡니다.
  - 스캔 PDF도 OCR(글자 인식)로 번역합니다.


[2] 처음 한 번 설치
  1. 압축을 풉니다.  (예: C:\OM_Translator)
  2. Python 3.12 설치 : https://www.python.org/downloads/
     ※ 설치 첫 화면에서 "Add python.exe to PATH" 반드시 체크
  3. OM_Translator.pyw 더블클릭
     → 필요한 부품 자동 설치 (1~3분, 처음 한 번만)
     ※ 반응이 없으면: 우클릭 → 연결 프로그램 → Python
  4. "API 키" 칸에 키 붙여넣기 → [저장] → "API 키 확인됨" 확인
     (키 발급: https://console.anthropic.com → API Keys,
      Billing 에서 크레딧 충전)
  5. [Tesseract(OCR) 설치] 한 번 클릭  (스캔 PDF용)
  6. (선택) [바탕화면 바로가기 만들기]


[3] 번역하기
  1. [PDF 추가…] 또는 [폴더 추가…] 로 파일 선택
  2. 모델 선택 : Sonnet(권장) / Haiku(저렴) / Opus(고품질)
  3. [비용 추정] → 예상 비용 확인  (무료, API 사용 안 함)
  4. 페이지 칸에 1-5 입력 → [▶ 번역 시작] → 결과 확인
  5. 이상 없으면 페이지 칸을 비우고 전체 번역
  6. [한국어 PDF 열기] / [번역 로그 열기] / [결과 폴더]

  ※ 중지하거나 창을 닫아도 다시 시작하면 이어서 진행합니다.
  ※ 한 번 번역한 문구는 다시 비용이 들지 않습니다.


[4] 결과물  (output 폴더)
  - 원본파일명_KR_O&M.pdf          → 한국어 PDF
  - 원본파일명_Translation_Log.xlsx → 번역로그 / 페이지 / 최종검사
  ※ "최종검사" 시트가 모두 OK 인지 확인하세요.


[5] 번역 고치기
  1. Translation_Log.xlsx 의 "수정 번역(입력)" 열에 입력 후 저장
  2. "이미 번역된 파일도 다시 만들기" 체크 → [▶ 번역 시작]
  ※ 고친 번역은 다른 문서에도 똑같이 적용됩니다.
  ※ 용어 통일은 [용어집 열기] (예: trip=트립, ko 칸에 KEEP=영어 유지)


[6] 비용 추정
  - 여러 파일(폴더 통째)을 넣으면 파일별 비용과 전체 합계가 나옵니다.
  - 결과는 logs\비용추정_날짜.csv 로도 저장됩니다. (Excel 로 열기)
  - 스캔 페이지 분량은 합계에서 빼고 "대략 추가 비용"으로 따로 표시합니다.


[7] 주의
  - WARNING/CAUTION, 설정값, 인터록, 트립 조건은
    반드시 사람이 검수한 뒤 제출하십시오.
  - 문서 내용이 Claude API(Anthropic)로 전송됩니다.
    고객·제작사 NDA 및 사내 보안 규정을 확인하십시오.
  - API 키를 메일·메신저로 보내지 마십시오.
    (키는 각 PC 의 .env 파일에만 저장되며, 이 압축 파일에는 없습니다)


[8] 문제 해결
  - API 키 오류       → 키를 다시 복사해 [저장]
  - 잔액 부족         → console.anthropic.com → Billing 충전 후 다시 시작
  - 연결·인증서 오류  → 회사망 문제. IT 에 api.anthropic.com(443) 허용 요청
  - 스캔 쪽이 영어로  → [Tesseract(OCR) 설치] 후 "다시 만들기" 체크
  - PDF 저장 실패     → Bluebeam 에서 결과 PDF 를 닫고 다시 실행
  - 그 밖의 오류      → [로그 폴더] 의 로그 파일 확인
