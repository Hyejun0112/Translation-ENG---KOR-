# Plant O&M Translator v2.0 (Claude API)

발전플랜트 O&M Manual(Boiler, Steam Turbine, Fuel Handling, Mechanical, Electrical, Instrument) PDF를
**원본 레이아웃(그림·표·도면·배경·선) 그대로 두고 O&M 대상 문구만 한국어로 바꾼 PDF**로 번역합니다.
Word 원본이 없어도 되고, 스캔 PDF / 글자가 깨져 복사되는 PDF도 OCR로 처리합니다.

```
OM_Translator.pyw 더블클릭 → API 키 저장(처음 한 번) → [PDF 추가] → [▶ 번역 시작] → output\원본파일명_KR_O&M.pdf
```

---

## 1. 처음 한 번 준비

1. **Python 3.12** 설치: https://www.python.org/downloads/ → 설치 화면에서 **"Add python.exe to PATH" 체크**
2. 프로젝트 폴더에서 **`OM_Translator.pyw` 더블클릭**
   → "처음 실행 준비" 창이 뜨고 필요한 부품을 자동 설치합니다 (1~3분, 한 번만). 끝나면 프로그램 창이 열립니다.
3. **Claude API 키** 입력 → **[저장]**
   - 키 발급: https://console.anthropic.com → API Keys → Create Key (`sk-ant-`로 시작), Billing 에서 크레딧 충전
   - 키는 이 PC의 `.env` 파일에만 저장됩니다. `.env`는 `.gitignore`에 들어 있어 **GitHub에 올라가지 않습니다.**
   - **키를 코드나 채팅, 메일에 붙여넣지 마세요.** (이 저장소는 공개 저장소입니다)
4. 프로그램 창 아래 **[Tesseract(OCR) 설치]** 를 한 번 눌러 둡니다 (스캔/글자깨짐 페이지, 목차 등에 필요)
5. (선택) **[바탕화면 바로가기 만들기]** → 다음부터 바탕화면 'OM 번역기' 아이콘으로 실행

> `.pyw` 파일이 더블클릭으로 열리지 않으면: 파일 우클릭 → 연결 프로그램 → **Python** 선택.

## 1-1. API 결제 후 첫 실행 (점검 순서)

1. `git pull` 로 최신 코드 받기 → **`OM_Translator.pyw` 더블클릭** (부품 목록이 바뀌었으면 처음 실행 준비 창이 떠서 자동 업데이트)
2. API 키 붙여넣기 → [저장] → 오른쪽 위에 **"API 키 확인됨"** 이 뜨는지 확인
   - "키가 올바르지 않습니다" → 키를 다시 복사. "연결 확인 불가" → 회사망 문제일 수 있음 (아래 문제 해결 표)
3. 번역할 PDF 추가 → **[비용 추정]** → 모델별 예상 비용(USD) 확인 (API 사용 안 함, 무료)
4. **페이지 `1-5`** 로 먼저 번역 → 결과 PDF 와 `Translation_Log.xlsx` 의 최종검사 확인
5. 이상 없으면 페이지 칸을 비우고 전체 번역. 진행 기록 마지막 줄에 **API 사용량과 예상 비용**이 표시됩니다
6. (선택) `python tools\check_translation.py 원본.pdf output\원본_KR_O&M.pdf` 로 숫자/Tag/조사 점검

**API 호출 방식** (비용·안정성)
- 번역 깊이(effort)는 `low` (번역에는 깊은 추론이 필요 없음 → 비용·시간 절약). `config.py` 의 `TRANSLATION_EFFORT` 또는
  `.env` 의 `OM_EFFORT=medium` 으로 바꿀 수 있습니다
- 시스템 프롬프트는 캐시되어 두 번째 호출부터 그 부분 입력 비용이 약 1/10
- 결과는 JSON 형식이 보장되는 구조화 출력으로 받고, 응답이 잘리거나 형식이 깨지면 묶음을 반으로 나눠 다시 요청
- 과부하(529)·속도 제한(429)·일시적 연결 오류는 자동 재시도
- **키 오류 / 잔액 부족 / 모델 없음 / 회사망 인증서 문제**는 즉시 번역을 멈추고 원인을 알려 줍니다
  (그때까지 번역한 문구는 저장되어, 해결 후 다시 시작하면 이어서 진행 - 같은 문구는 다시 비용이 들지 않음)
- 회사망(SSL 검사 프록시)에서는 Windows 인증서 저장소를 사용합니다 (truststore)

## 2. 사용 방법

1. **[PDF 추가…]** 또는 **[폴더 추가…]** 로 번역할 PDF 선택 (여러 개 가능, `input\pdf` 폴더의 PDF는 자동 표시)
2. 옵션 확인
   - **모델**: Sonnet(권장, 품질/비용 균형) · Haiku(빠르고 저렴) · Opus(최고 품질, 비용 높음)
   - **페이지**: 비우면 전체, 처음에는 `1-5`로 샘플 확인 권장
3. (선택) **[비용 추정]** → 번역할 문구 수, 예상 토큰, 모델별 예상 비용(USD) 확인 (무료)
   - 여러 파일(폴더 통째)도 한 번에 추정합니다. **파일별 예상 비용**과, 파일끼리 겹치는 문구를 한 번만 센 **전체 합계**가 나오고
     `logs\비용추정_날짜.csv` 로도 저장됩니다 (Excel 로 열어 보고용으로 사용).
   - 추정만 할 때는 원본을 `input\pdf` 로 복사하지 않습니다 (대용량 파일도 디스크 부담 없음).
   - 스캔 페이지는 OCR 전에는 글자 수를 알 수 없어 합계에서 빼고, 글자층 있는 쪽의 쪽당 평균으로 환산한 **대략 추가 비용**을 따로 보여 줍니다.
4. **[▶ 번역 시작]** → 전체/현재 파일 진행률, 남은 시간 표시
5. 끝나면 **[한국어 PDF 열기]**, **[번역 로그 열기]**, **[결과 폴더]**

- 중간에 **[■ 중지]** 하거나 창을 닫아도 번역된 문구는 저장되어 있어 다시 시작하면 이어서 진행합니다.
- 같은 문구는 번역 메모리에서 재사용하므로 다시 만들 때 **API 비용이 다시 들지 않습니다.**

## 3. 결과물 (`output` 폴더)

| 파일 | 내용 |
|---|---|
| `원본파일명_KR_O&M.pdf` | 한국어 O&M 문서. 원본과 같은 페이지 수·크기·순서, 텍스트 검색 가능 |
| `원본파일명_Translation_Log.xlsx` | **번역로그**(원문/번역/상태/비고) · **페이지**(번역/원문유지와 사유) · **최종검사** |
| `Plant_O&M_Glossary.xlsx` | 적용된 용어집 + 자주 나오는 미등록 용어 후보 (누적) |

**번역 수정**: `Translation_Log.xlsx`의 **`수정 번역(입력)`** 열에 고쳐 쓰고 저장 → 같은 PDF로 다시 [번역 시작]
→ 수정이 반영되고, 번역 메모리에 저장되어 다른 문서에도 똑같이 적용됩니다.

## 4. 번역 규칙

- **번역**: 제목, 본문, 글머리표, 절차, WARNING/CAUTION/NOTE, 표 머리글·지시문, 그림 제목, 북마크
- **페이지 전체 원문 유지 (Drawing / Datasheet 제외)**: 제목이 Datasheet, Technical Data, Parts List, Bill of Material,
  Certificate, P&ID, PFD, Logic/Wiring/Single Line Diagram, GA/Arrangement/Dimensional Drawing 등인 페이지, A3 이상 도면 페이지
  (본문 속 "P&ID No. 0061" 같은 참조는 무시하고, 문장 위주 페이지는 번역)
- **표지·문서 송부 양식·문서 목록은 항상 번역**: 문서 제목에 "Data sheets", "Catalogue" 같은 말이 들어 있어도
  표지(JOB TITLE / DOC NO. / VENDOR …, Subject / Document code / Checked by …)와 Table of Contents, Document List 페이지는 번역합니다.
- **표**: 셀 단위 번역, 셀 안에서 줄바꿈. 머리글이 Tag/Model/Parameter/Code/Value/Unit 인 **열은 원문 유지**
- **항상 원문 유지 (Tag 보호)**: Tag No., 모델/부품/도면/문서번호, Rev., 수치+단위, 2oo3, 화학식, 규격, 약어, URL.
  번역 결과에서 보호 값이 빠지면 잘못된 번역을 넣지 않고 원문을 유지
- **용어집** `data\glossary.csv` ([용어집 열기] 버튼, Excel로 편집): operation=운전, maintenance=정비, start-up=기동, trip=트립 …,
  WARNING=경고, CAUTION=주의, NOTE=참고. `ko`가 `KEEP`이면 영어 유지
- 문체: 설명문 "~합니다", 지시문 "~하십시오" (Check→확인하십시오, Open→여십시오, Do not→하지 마십시오 …)

## 4-1. 레이아웃 보존 규칙 (원본 그대로 유지되는 것)

- **그림·표 괘선·도면·로고**: 글자만 지우고 다시 씁니다. 지울 때는 문구 상자 전체가 아니라 **원문 줄마다 글자가 찍힌 자리만** 지워
  옆의 번호(`2.`), 수식 기호, 이웃 줄이 함께 지워지지 않습니다.
- **주석(Bluebeam Markup, 스탬프, 서명, 글상자)·링크·북마크**: 번역 전에 떼어 두었다가 저장 직전에 원본 그대로 다시 붙입니다.
  주석 안의 글자(검토 스탬프 문구 등)는 번역하지 않습니다.
- **표의 행/열**: 세로선·가로선이 없는 표도 행 단위로 인식합니다 (기호 | 설명 목록, `less than` 같은 반복 열, 칸 안의 숨은 열).
  표의 첫 열이 새 항목으로 시작하면 새 행으로 보고, 애매하면 합치지 않습니다.
- **문단**: 줄 간격이 넓어지는 곳, 줄을 일부러 바꾼 곳(다음 줄 첫 단어가 앞 줄 빈자리에 들어갈 수 있었던 경우),
  글자 크기가 바뀌는 곳(라벨/값), 밑줄 제목에서 문단을 나눕니다.
- **밑줄 제목**: 원래 밑줄을 지우고 번역문 길이에 맞춰 다시 긋습니다 (일부만 밑줄이면 같은 비율로).
- **수식·기호**: 수식 글꼴(Cambria Math 등)과 첨자가 붙은 기호(P wbox, T bed ave)는 원본 그대로 둡니다.
  `cm²`, `Nm³/h`, `H₂O` 같은 위/아래 첨자 숫자는 번역 후에도 첨자로 남습니다.
- **한글 글꼴에 없는 기호**(−, ≤, µ, ₂ …): 대체 글꼴(Arial, Segoe UI Symbol 등)로 그려 □ 로 깨지지 않게 합니다.
  어느 글꼴에도 없으면 같은 뜻의 기본 글자로 바꾸고, 그래도 안 되면 그 문구는 원문을 유지합니다.

- **글머리표·번호**: 글머리표(•, ▪, ①②③ …)는 원본 그대로 두고 글만 번역합니다. 스페이스로 들여쓴 줄,
  "1. …" 항목의 둘째 줄 내어쓰기, 양쪽 정렬로 낱말 사이가 벌어진 문장도 원래 모양을 유지합니다.
- **제작사 글꼴 전용 아이콘**(E+H 매뉴얼의 `→ [문서 아이콘] 8` 쪽 참조 등): 아이콘과 쪽번호는 원본 그대로 두고
  나머지만 번역합니다. 문장 중간의 아이콘은 생략하고 번역 로그에 `ICON_DROPPED` 로 남깁니다.
- **스캔 페이지(OCR)**
  - 사진 속 글자(간판·명판·로고)와 무늬 배경 위의 짧은 글자는 읽지 않습니다 → 사진 위에 번역문을 덧씌우지 않습니다.
  - 신뢰도가 낮은 조각(그림·괘선을 글자로 잘못 읽은 것)은 버리고 원본 그림 그대로 둡니다.
  - 글자 크기는 낱말의 글자 모양(위·아래로 뻗는 글자 유무)으로 환산하고, 한 페이지 안에서는 몇 가지 대표 크기로 맞춥니다.
  - 목록의 각 줄은 한 문단으로 합치지 않습니다 (본문과 같은 줄바꿈 규칙).
- **원문 유지 페이지 판단 보강**
  - 표제란이 페이지 아래/구석에 있는 양식(INSTRUMENT SPECIFICATION, DATA SHEET, DIMENSIONAL DRAWING …)
  - 제목이 글자로 남아 있지 않아도 표 칸의 항목이 거의 다 대문자 낱말인 양식(전동기 데이터시트 등)
  - 그림 조각이 2,000개를 넘는 페이지(특성 곡선·도면을 잘게 나눠 저장한 것): 글자 지우기가 매우 느리고 위험
  - 표의 한 행 이름("Wiring Diagram | 도면번호")이나 그림 설명문은 제목으로 보지 않습니다.

- **같은 문서의 쪽은 같은 대우**: 제작사 데이터시트나 회로도처럼 제목이 있는 쪽과 없는 쪽이 섞여 있어도,
  앞쪽과 뒤쪽이 모두 원문 유지인 쪽은 (문장 위주 쪽이 아니면) 함께 원문 유지합니다. 회로도(`Circuit Diagram Number`,
  `BASIC DIAGRAM` 표제란)는 도면으로 보고 원문 유지합니다.
- **조사 자동 보정**: Tag/숫자/영문 약어 뒤의 조사가 `PUB002-041을(를)`, `PS1은(는)` 처럼 병기된 채 나오면 앞 글자에 맞게
  `을`/`는`/`를`/`로` 로 고칩니다 (한글은 받침, 숫자는 일·이·삼…, 영문 대문자는 에이·비·씨… 로 읽을 때의 소리 기준).
  번역 메모리에서 가져온 예전 번역도 같이 보정됩니다.
- **번호 붙은 대문자 제목**(`1.FUSES:`, `2.REMOTE CONTROL:`)은 번호만 보호하고 낱말은 번역합니다 (예전에는 통째로 Tag 로 보호되어 영어로 남음).
- **스캔(OCR) 쪽의 로고·아이콘**: 글머리표(❯, •)와 로고(`IQ` 등)를 글자로 잘못 읽어 번역문에 `Q)`, `)` 같은 잡음이 끼던 것을
  글에서 떼어 내고 원본 그림에 그대로 둡니다.
  쪽 위·아래 가장자리에 크게 겹쳐 쌓인 회사 로고 글자(예: `Minebea` / `intec`)와 그 바로 옆 슬로건(`The true measure`)은
  번역하지 않고 원본 그대로 둡니다 (번역 로그 `로고 글자(스캔) → 원문 유지`).
- **위·아래로 겹친 줄 보호**: 분수식(`6 x rpm` / `63,000`)의 분모, 머리글 제목 아래의 문서번호(`D103556X012`)처럼
  글자 상자가 이웃 줄과 겹쳐 있어도, 번역할 줄을 지울 때 이웃 줄 글자는 지우지 않습니다.
  한 줄 안에서 높이를 바꿔 찍은 수식(분자·`+`·`=`)은 조각별로 제자리에 둡니다.
- **오른쪽 정렬 머리글**: 오른쪽 끝이 같은 위·아래 두 줄(`Quick Start Guide` / 문서번호)은 번역 후에도 오른쪽 끝을 맞춥니다.
- **보이는 하이픈**: 줄 중간의 U+00AD 는 실제로 찍힌 하이픈이므로 남깁니다 (`MTV-A5-AAA-A11-DN100` 이 `MTVA5AAAA11DN100` 으로 바뀌지 않음).
- **기호 글꼴의 ©·® 등**(제어 문자 번호로 저장된 기호)은 원본 그대로 둡니다.
- **추가 보호 대상**: 파일 이름(`mda4201.pdf`, `5230_ethernetip.eds`), 밑줄 식별자(`bk212_steamtrap_manual`),
  소문자 꼬리 모델명(`DVC6200f`), 대소문자 섞인 재질/규격 코드(`CK3MCuN`, `AlSi10Mg`), 홀로 쓴 유량 단위(`gpm`, `scfm`, `gal/rev`).
- **스캔 표 머리글의 두 행 글자**(`Actuator` 아래 `size`): OCR 이 두 행을 한 줄로 묶어 다시 읽으면 상자가 두 행 높이가 되어
  아래 행 번역문과 겹치던 것을, 해당 행만 다시 읽어 상자를 실제 글자 높이로 맞춥니다.
- **OCR 이 잘못 읽은 식별자 교정**: `1Q3` → `IQ3`, `PUBOO2-137` → `PUB002-137` 처럼 같은 문서의 다른 곳(글자층 포함)에 올바른 철자가
  있을 때만 모양 기준으로 고칩니다. 고친 문구는 번역 로그에 `OCR_FIXED` 로 남습니다.
- **일부 쪽만 번역(`페이지: 1-25`)**: 결과 PDF 에 원본의 북마크(번역된 제목, 새 쪽번호로 연결)와 문서 정보가 그대로 이어지고,
  Bluebeam Markup/스탬프도 유지됩니다.

**번역 내용 점검 도구** (API 사용 안 함) - 실제 번역본을 받은 뒤 원본과 쪽 단위로 대조합니다.

```
python tools\check_translation.py 원본.pdf output\원본_KR_O&M.pdf [--pages 1-25]
```
숫자·Tag·문서번호가 번역 중에 바뀌거나 사라졌는지, 조사가 `을(를)` 로 남은 곳, OCR 오독으로 보이는 식별자, 영어가 많이 남은 쪽,
**번역된 쪽에 영어 문장으로 남은 줄(번역 누락 후보, 메모 주석 안의 글은 제외)** 을 알려 줍니다.
(`check_layout.py` 는 그림/선/겹침 같은 모양을, 이 도구는 글 내용을 봅니다.)

- 90° 돌려 쓴 글자(표 옆 세로 문구, 세로 표 머리글)도 같은 방향으로 번역해 넣습니다.
- 문장 중간의 키 모양 아이콘(`Press [아이콘] to select …`)은 번역문의 해당 자리로 함께 옮겨 다시 그립니다.
  번역 로그에는 아이콘 자리가 `⟦I3⟧` 처럼 표시됩니다 (수정 번역을 입력할 때도 이 표시를 그대로 두세요).
- 그림 속 아주 작은 글자(3pt 미만: 명판·키 라벨)는 그림을 덮지 않도록 원문 그대로 둡니다.

**최종검사 시트**(`Translation_Log.xlsx`)에서 `그림/사진 유지`, `표 괘선/도형 유지`, `주석/링크 유지`, `글꼴에 없는 글자`,
`텍스트 겹침`이 모두 OK인지 확인하세요. 여러 문서를 한꺼번에 돌린 뒤에는 아래 도구로 원본과 자동 대조할 수 있습니다.

```
python tools\check_layout.py 원본.pdf output\원본_KR_O&M.pdf --png logs\check
```
이상이 있는 페이지 번호와 사유(그림/선 차이, 주석 개수, 깨진 글자, 글자 겹침, 영어 남음)를 출력하고,
`--png` 폴더에 원본/번역본을 나란히 붙인 그림을 저장합니다 (API 사용 안 함).
그림/선 차이는 글자 줄 주변(다시 그린 밑줄, 같은 행 글자 조각 사이의 줄 속 아이콘 자리)과 스캔 쪽의 덧씌운 패치 자리를 빼고 비교하므로,
표시되면 그림·괘선·로고가 실제로 바뀐 것입니다. '영어 남음'은 원문 유지 쪽(데이터시트·도면)이면 정상입니다.

## 5. 폴더 구조

```
├─ OM_Translator.pyw           ★ 실행 (더블클릭) - 처음 실행 준비 + 프로그램 창
├─ gui.py                      프로그램 창 (API 키, PDF 선택, 진행률, 결과 열기)
├─ main.py                     번역 파이프라인 (프로그램 창이 내부적으로 실행)
├─ config.py                   설정 (모델, 동시 요청 수, OCR, 번역 범위)
├─ requirements.txt
├─ engines\
│   ├─ translation_engine.py   Claude API 번역, 번역 메모리, 진행률
│   ├─ pdf_engine.py           페이지 진단, 텍스트 추출, 레이아웃 유지 한글 삽입
│   ├─ glossary_engine.py      용어집, Tag/숫자/단위 보호
│   ├─ table_engine.py         표 셀 인식, Tag/Value 열 원문 유지
│   ├─ scope_engine.py         Drawing / Datasheet 제외 판단
│   ├─ ocr_engine.py           스캔 PDF OCR (Tesseract + OpenCV)
│   └─ qa_engine.py            최종 검사, Translation Log, Glossary Excel
├─ data\                       glossary.csv, keep_patterns.txt, scope_keywords.txt
├─ tools\install_tesseract.py  Tesseract 자동 설치
├─ tools\check_layout.py       원본 ↔ 번역본 페이지별 자동 대조 (레이아웃 검사)
├─ tools\check_translation.py  원본 ↔ 번역본 내용 대조 (숫자/Tag/조사/OCR 오독)
├─ input\pdf\                  (선택) 원본 PDF를 넣어 두면 목록에 자동 표시
├─ output\                     결과
├─ cache\                      번역 메모리 / OCR 캐시 / 화면 설정
├─ logs\                       실행 로그 (문제가 생기면 이 파일을 확인)
└─ .env                        API 키 (이 PC에만 있음, GitHub 제외)
```

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| `.pyw` 더블클릭해도 반응 없음 | 우클릭 → 연결 프로그램 → Python. 또는 Python 3.12 재설치(PATH 체크) |
| "보안 인증서 확인에 실패했습니다" / "연결할 수 없습니다" | 회사망(SSL 검사 프록시·방화벽) 문제. `.venv\Scripts\python -m pip install truststore` 확인, 그래도 안 되면 IT 담당자에게 `api.anthropic.com` (HTTPS 443) 허용 요청 |
| "API 크레딧(잔액)이 부족하거나 사용 한도에 도달" | console.anthropic.com → Billing 에서 잔액/월 사용 한도 확인. 충전 후 다시 시작하면 이어서 진행 |
| "API 키가 올바르지 않습니다" | console.anthropic.com 에서 키를 다시 복사해 [붙여넣기] → [저장] |
| "크레딧(잔액)이 부족합니다" | console.anthropic.com → Billing 에서 충전 |
| "필요한 패키지가 없는 Python 으로 실행되었습니다" | 프로그램 창을 VS Code(F5)나 `python gui.py` 로 열면 시스템 Python 이 쓰입니다. 엔진은 자동으로 `.venv` 의 Python 으로 다시 실행되며, `.venv` 가 없으면 **OM_Translator.pyw 더블클릭**으로 한 번 만들어 주세요 |
| 목차/스캔 페이지가 영어로 남음 | [Tesseract(OCR) 설치] 후 [이미 번역된 파일도 다시 만들기] 체크하고 다시 번역 |
| 결과 PDF 저장 실패 | Bluebeam 등에서 결과 PDF를 닫거나, 자동으로 `_시간` 붙은 이름으로 저장됨 |
| 그 밖의 오류 | 진행 기록의 빨간 줄, 또는 [로그 폴더]의 로그 파일 확인 |
